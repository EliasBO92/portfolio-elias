# Portfolio Elias Ben-Othman

Site portfolio statique en HTML, CSS et JavaScript.

## Pages

- `index.html` : accueil et questionnaire interactif
- `projets.html` : projets informatiques
- `parcours.html` : parcours, compétences et expériences professionnelles
- `contact.html` : formulaire de contact et liens utiles

## Déploiement

### GitHub Pages

1. Créer un dépôt GitHub.
2. Envoyer tous les fichiers de ce dossier à la racine du dépôt.
3. Dans GitHub, aller dans `Settings > Pages`.
4. Choisir `Deploy from a branch`, puis `main` et `/root`.

### Netlify

1. Importer le dépôt GitHub dans Netlify.
2. Laisser le dossier de publication sur `.`.
3. Il n’y a pas de commande de build.

### Vercel

1. Importer le dépôt GitHub dans Vercel.
2. Choisir un projet statique.
3. Il n’y a pas de commande de build.
